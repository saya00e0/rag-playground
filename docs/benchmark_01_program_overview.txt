ベンチマーク用合成文書 — Atlas プログラム概要

この文書群は Vector RAG と GraphRAG の検索評価専用に作成した架空の資料であり、実在の顧客、従業員、システム、秘密情報は含まれない。

Atlas は社内ナレッジ検索を改善する2026年度のプログラムである。プログラム責任者はプロダクト部の佐藤真央で、技術責任者はプラットフォーム部の田中健である。最初の対象業務は、調達部が管理する製品仕様書の検索である。

Atlas の最初のリリースは「Orion 2.1」と呼ぶ。Orion 2.1 は Catalog Service、Policy Service、Vector Index の三つを利用する。公開の可否は Policy Service が判定し、検索候補の生成は Vector Index が担当する。

成功指標は、仕様書検索の上位3件再現率と、検索要求の平均応答時間である。ベンチマーク結果はこの合成 corpus の範囲に限定して解釈する。
