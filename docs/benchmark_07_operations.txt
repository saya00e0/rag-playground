ベンチマーク用合成文書 — Atlas 運用手順

この文書は評価専用の架空情報である。

Atlas の定期メンテナンスは毎月第2日曜日の午前1時から3時までである。メンテナンス中、Gateway API は計画停止し、検索要求を受け付けない。高橋悠は開始前に社内ポータルへ告知を掲載し、完了後に疎通確認を行う。

検索失敗の一次対応は高橋悠が担当する。Gateway API または Catalog Service の技術問題は田中健へ、Policy Service のアクセス規則問題は鈴木梨奈へエスカレーションする。

検索要求の平均応答時間が2秒を超える状態が15分続いた場合、高橋悠は性能障害として記録する。Vector Index の候補検索時間と Policy Service の判定時間を分けて確認する。
