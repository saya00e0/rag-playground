ベンチマーク用合成文書 — Orion 2.1 受入条件

この文書は評価専用の架空情報である。

Orion 2.1 は調達部の製品仕様書を対象に受入試験を行う。試験では、Catalog Service が Vector Index から候補を取得し、Policy Service が未設定規則の文書を除外することを確認する。

合格条件は、定義済みの評価セットに対する上位3件再現率が0.80以上であること、平均検索応答時間が2秒以下であること、規則が未設定の文書IDを Gateway API が返さないことである。

田中健は性能と候補検索の試験結果を、鈴木梨奈はアクセス規則の試験結果を提出する。佐藤真央は両方の結果と伊藤彩の仕様書サンプル確認を受けて、公開可否を決定する。
