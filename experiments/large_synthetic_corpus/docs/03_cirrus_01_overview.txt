合成ベンチマーク文書 — Cirrus プログラム 概要

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

Cirrus は 第3調達部 の製品仕様書検索を改善する社内プログラムです。プログラム責任者は 渡辺紬、技術責任者は 吉田蓮 です。最初の公開対象は、調達部が更新する仕様書と承認済みの付属資料です。

最初のリリースは Cirrus 3.3 です。Cirrus 3.3 は Cirrus Catalog Service、Cirrus Policy Service、Cirrus Vector Index、Cirrus Gateway API を利用します。検索候補の生成は Cirrus Vector Index、公開規則の判定は Cirrus Policy Service、利用者への応答は Cirrus Gateway API が担当します。

成功指標は上位3件再現率、平均検索応答時間、未承認文書を返さないことです。公開可否は 渡辺紬 が最終判断しますが、判断前には技術、セキュリティ、調達確認が必要です。

このプログラムでは文書名、担当者名、サービス名が文書ごとに別の表現で現れることがあります。評価では、同一プロジェクトの関係を結びつける検索能力だけを確認し、別プロジェクトの同名概念を正解とみなしません。
