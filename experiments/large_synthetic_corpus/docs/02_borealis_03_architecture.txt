合成ベンチマーク文書 — Borealis プログラム アーキテクチャ

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

利用者の検索要求は Borealis Gateway API を通り Borealis Catalog Service に渡されます。Borealis Catalog Service は Borealis Vector Index に候補検索を依頼し、候補の文書IDを受け取ります。その後、Borealis Catalog Service は候補を Borealis Policy Service に渡します。

Borealis Policy Service は利用者の所属と文書の公開規則を照合し、許可した候補だけを Borealis Gateway API に返します。Borealis Vector Index は公開可否を判定しません。アクセス規則の変更は Borealis Vector Index ではなく Borealis Policy Service に反映する必要があります。

Borealis Catalog Service の所有チームはプラットフォーム部で、設計責任者は 中村陸 です。Borealis Policy Service の公開前レビュー責任者は 小林葵 です。Borealis Gateway API の稼働状況は 加藤湊 が監視します。

この構成では、候補検索、規則判定、応答送信は別サービスです。質問が「どのサービスが候補を作るか」を尋ねる場合と、「どのサービスが未承認文書を除外するか」を尋ねる場合では、異なる証拠文書が必要になります。
