合成ベンチマーク文書 — Grove プログラム 外部連携記録

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

Grove は 第7調達部 の仕様書更新を毎営業日に受け取ります。福田紬 が更新通知を確認した後、Grove Catalog Service の登録候補一覧に文書IDを追加します。登録候補が公開される前には、Grove Policy Service の規則レビューが必要です。

Grove Catalog Service は候補検索時に Grove Vector Index を利用しますが、公開規則を保存または上書きしません。規則の状態は Grove Policy Service が管理し、利用者への返却可否は Grove Gateway API の応答直前に確認されます。

連携停止が発生した場合、藤井晴 が一次対応を記録し、技術的な原因は 後藤蒼 が調査します。規則誤りが原因の場合は 西村楓 が確認します。

この記録は更新通知とサービス連携の関係を示します。公開の最終判断者と公開延期の連絡先は担当者・リリース文書で確認します。
