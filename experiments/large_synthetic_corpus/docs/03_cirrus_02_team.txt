合成ベンチマーク文書 — Cirrus プログラム 担当者と連絡経路

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

渡辺紬 は Cirrus の公開判断、優先順位、第3調達部 との調整を担当します。吉田蓮 は Cirrus Catalog Service と Cirrus Vector Index の設計、性能問題の技術調査、負荷試験を担当します。

斎藤結 は Cirrus Policy Service のアクセス規則、公開前レビュー、規則違反時の判断材料の整理を担当します。岡田晴 は監視、一次対応、定期メンテナンス、復旧確認を担当します。石井凛 は 第3調達部 の窓口であり、仕様書更新とサンプル確認を担当します。

Cirrus Gateway API または Cirrus Catalog Service の技術問題は 吉田蓮 へエスカレーションします。Cirrus Policy Service のアクセス規則問題は 斎藤結 へエスカレーションします。公開延期の連絡は 渡辺紬 が 石井凛 に行います。

担当者一覧は役割を示すための文書であり、障害の詳細や公開条件そのものは別文書にあります。したがって、担当者と具体的な手順を同時に問う質問では、少なくとも二つの文書を必要とします。
