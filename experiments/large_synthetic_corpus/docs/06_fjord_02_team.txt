合成ベンチマーク文書 — Fjord プログラム 担当者と連絡経路

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

林真央 は Fjord の公開判断、優先順位、第6調達部 との調整を担当します。斉藤陽菜 は Fjord Catalog Service と Fjord Vector Index の設計、性能問題の技術調査、負荷試験を担当します。

坂本蓮 は Fjord Policy Service のアクセス規則、公開前レビュー、規則違反時の判断材料の整理を担当します。村上葵 は監視、一次対応、定期メンテナンス、復旧確認を担当します。近藤凛 は 第6調達部 の窓口であり、仕様書更新とサンプル確認を担当します。

Fjord Gateway API または Fjord Catalog Service の技術問題は 斉藤陽菜 へエスカレーションします。Fjord Policy Service のアクセス規則問題は 坂本蓮 へエスカレーションします。公開延期の連絡は 林真央 が 近藤凛 に行います。

担当者一覧は役割を示すための文書であり、障害の詳細や公開条件そのものは別文書にあります。したがって、担当者と具体的な手順を同時に問う質問では、少なくとも二つの文書を必要とします。
