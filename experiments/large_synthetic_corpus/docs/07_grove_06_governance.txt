合成ベンチマーク文書 — Grove プログラム 公開ガバナンス

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

第7調達部 の製品仕様書は、福田紬 が更新を確認した後に公開候補となります。公開候補は Grove Catalog Service に登録される前に Grove Policy Service のアクセス規則レビューを受けます。レビュー責任者は 西村楓 です。

公開規則には「第7調達部のみ」「全社公開」「指定プロジェクトのみ」の三種類があります。規則が未設定の文書は公開してはなりません。Grove Policy Service が拒否した文書IDは Grove Gateway API から利用者へ返してはなりません。

公開規則に問題が見つかった場合、西村楓 は 石川澪 へ報告します。公開可否の最終判断は 石川澪 が行います。福田紬 は判断後の仕様書状態を 第7調達部 に確認します。

ガバナンス文書は公開規則と判断経路を示します。候補検索の仕組みはアーキテクチャ文書、公開日の前提条件はリリース計画にあります。
