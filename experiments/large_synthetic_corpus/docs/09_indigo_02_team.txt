合成ベンチマーク文書 — Indigo プログラム 担当者と連絡経路

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

中川楓 は Indigo の公開判断、優先順位、第9調達部 との調整を担当します。小川蒼 は Indigo Catalog Service と Indigo Vector Index の設計、性能問題の技術調査、負荷試験を担当します。

平野澪 は Indigo Policy Service のアクセス規則、公開前レビュー、規則違反時の判断材料の整理を担当します。川口晴 は監視、一次対応、定期メンテナンス、復旧確認を担当します。青木紬 は 第9調達部 の窓口であり、仕様書更新とサンプル確認を担当します。

Indigo Gateway API または Indigo Catalog Service の技術問題は 小川蒼 へエスカレーションします。Indigo Policy Service のアクセス規則問題は 平野澪 へエスカレーションします。公開延期の連絡は 中川楓 が 青木紬 に行います。

担当者一覧は役割を示すための文書であり、障害の詳細や公開条件そのものは別文書にあります。したがって、担当者と具体的な手順を同時に問う質問では、少なくとも二つの文書を必要とします。
