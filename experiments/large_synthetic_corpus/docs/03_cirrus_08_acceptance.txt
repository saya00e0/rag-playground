合成ベンチマーク文書 — Cirrus プログラム 受入条件

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

Cirrus 3.3 は 第3調達部 の製品仕様書を対象に受入試験を行います。試験では、Cirrus Catalog Service が Cirrus Vector Index から候補を取得し、Cirrus Policy Service が未設定規則の文書を除外することを確認します。

合格条件は、定義済み評価セットに対する上位3件再現率が0.80以上、平均検索応答時間が2秒以下、規則が未設定の文書IDを Cirrus Gateway API が返さないことです。

吉田蓮 は性能と候補検索の試験結果を、斎藤結 はアクセス規則の試験結果を提出します。渡辺紬 は両方の結果と 石井凛 の仕様書サンプル確認を受けて、公開可否を決定します。

受入条件は合格基準を示します。実際の公開予定日と延期条件はリリース計画、サービス間の経路はアーキテクチャ文書を参照します。
