合成ベンチマーク文書 — Fjord プログラム 運用手順

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

Fjord の定期メンテナンスは 毎月第3日曜日の午前1時から3時 です。メンテナンス中、Fjord Gateway API は計画停止し、検索要求を受け付けません。村上葵 は開始前に社内ポータルへ告知を掲載し、完了後に疎通確認を行います。

検索失敗の一次対応は 村上葵 が担当します。Fjord Gateway API または Fjord Catalog Service の技術問題は 斉藤陽菜 へ、Fjord Policy Service のアクセス規則問題は 坂本蓮 へエスカレーションします。

平均検索応答時間が2秒を超える状態が15分続いた場合、村上葵 は性能障害として記録します。Fjord Vector Index の候補検索時間と Fjord Policy Service の判定時間を分けて確認します。

運用手順は監視と一次対応を説明します。障害の発生日時や原因は障害報告、公開延期の判断はリリース計画にあります。
