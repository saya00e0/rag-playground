合成ベンチマーク文書 — Harbor プログラム 担当者と連絡経路

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

岡本結 は Harbor の公開判断、優先順位、第8調達部 との調整を担当します。長谷川陸 は Harbor Catalog Service と Harbor Vector Index の設計、性能問題の技術調査、負荷試験を担当します。

原田葵 は Harbor Policy Service のアクセス規則、公開前レビュー、規則違反時の判断材料の整理を担当します。三浦陽 は監視、一次対応、定期メンテナンス、復旧確認を担当します。竹内凛 は 第8調達部 の窓口であり、仕様書更新とサンプル確認を担当します。

Harbor Gateway API または Harbor Catalog Service の技術問題は 長谷川陸 へエスカレーションします。Harbor Policy Service のアクセス規則問題は 原田葵 へエスカレーションします。公開延期の連絡は 岡本結 が 竹内凛 に行います。

担当者一覧は役割を示すための文書であり、障害の詳細や公開条件そのものは別文書にあります。したがって、担当者と具体的な手順を同時に問う質問では、少なくとも二つの文書を必要とします。
