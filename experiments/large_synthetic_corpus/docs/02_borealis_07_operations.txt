合成ベンチマーク文書 — Borealis プログラム 運用手順

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

Borealis の定期メンテナンスは 毎月第3日曜日の午前3時から5時 です。メンテナンス中、Borealis Gateway API は計画停止し、検索要求を受け付けません。加藤湊 は開始前に社内ポータルへ告知を掲載し、完了後に疎通確認を行います。

検索失敗の一次対応は 加藤湊 が担当します。Borealis Gateway API または Borealis Catalog Service の技術問題は 中村陸 へ、Borealis Policy Service のアクセス規則問題は 小林葵 へエスカレーションします。

平均検索応答時間が2秒を超える状態が15分続いた場合、加藤湊 は性能障害として記録します。Borealis Vector Index の候補検索時間と Borealis Policy Service の判定時間を分けて確認します。

運用手順は監視と一次対応を説明します。障害の発生日時や原因は障害報告、公開延期の判断はリリース計画にあります。
