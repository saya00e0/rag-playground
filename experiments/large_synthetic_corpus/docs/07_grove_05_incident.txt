合成ベンチマーク文書 — Grove プログラム 障害報告

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

2026年7月09日、Grove Gateway API の証明書更新失敗により Grove の検索要求が失敗しました。Grove Vector Index と Grove Policy Service は正常でした。藤井晴 が監視通知を受けて一次対応を開始し、証明書設定の技術調査を 後藤蒼 へエスカレーションしました。

後藤蒼 は Grove Gateway API の証明書設定を修正し、同日中に検索要求の復旧を確認しました。アクセス規則に変更はなかったため、西村楓 による Grove Policy Service の臨時レビューは不要でした。

この障害は公開判定前の高優先度障害として記録されましたが、復旧確認後に解決済みとなりました。再発防止として 藤井晴 は証明書期限の監視を追加します。

障害報告は一次対応と技術調査の実績を示します。通常時の技術エスカレーション経路は担当者一覧、公開延期の規則はリリース計画にあります。
