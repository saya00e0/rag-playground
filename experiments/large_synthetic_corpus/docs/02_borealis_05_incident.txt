合成ベンチマーク文書 — Borealis プログラム 障害報告

この文書は Vector RAG と GraphRAG の評価専用に作成した架空資料です。実在の組織、人物、顧客、認証情報、秘密情報は含みません。各事実は複数文書に意図的に分散しています。

2026年2月04日、Borealis Gateway API の証明書更新失敗により Borealis の検索要求が失敗しました。Borealis Vector Index と Borealis Policy Service は正常でした。加藤湊 が監視通知を受けて一次対応を開始し、証明書設定の技術調査を 中村陸 へエスカレーションしました。

中村陸 は Borealis Gateway API の証明書設定を修正し、同日中に検索要求の復旧を確認しました。アクセス規則に変更はなかったため、小林葵 による Borealis Policy Service の臨時レビューは不要でした。

この障害は公開判定前の高優先度障害として記録されましたが、復旧確認後に解決済みとなりました。再発防止として 加藤湊 は証明書期限の監視を追加します。

障害報告は一次対応と技術調査の実績を示します。通常時の技術エスカレーション経路は担当者一覧、公開延期の規則はリリース計画にあります。
